# SafeRunner V18.1 项目说明与快速上手指南

## 1. SafeRunner V18.1 简介

SafeRunner V18.1 是一款专为 Bash/Shell 脚本设计的轻量级、高可靠性安全扫描网关。它突破了传统静态正则匹配工具的物理天花板，引入了轻量级语义分析、污点追踪（Taint Analysis）以及智能告警去重机制。在保持极低系统开销的同时，V18.1 能够精准拦截复杂的数据流攻击和高级语法混淆，并彻底解决了死代码与注释引发的误报问题，是 DevOps 流水线与主机安全防护的得力助手。

## 2. 核心特性

- **深度语义解析**：摒弃简单的逐行正则匹配，具备基础的词法与控制流分析能力，自动剔除注释与死代码，告别告警疲劳。
- **污点追踪 (Taint Analysis)**：自动识别 `read`、环境变量等外部输入，追踪其在跨行变量拼接、数组赋值中的流转，精准拦截 `eval`、`bash -c` 等高危执行链。
- **高级混淆识别**：有效防御间接变量引用、数组执行、文件描述符重定向等 Bash 高级特性带来的隐藏威胁。
- **智能告警去重**：内置哈希指纹去重机制，同一行代码的同类威胁仅输出一次，确保扫描报告干净、专业、可读性极高。

## 3. 系统要求

- **操作系统**：Linux / macOS / Windows (WSL)
- **依赖环境**：Bash 4.0+
- **权限要求**：具备目标脚本的读取权限

## 4. 快速上手指南

### 4.1 获取与安装

将 SafeRunner V18.1 的核心脚本文件（如 `safe_runner.sh`）下载至本地，并赋予可执行权限：

```bash
chmod +x safe_runner.sh
```

### 4.2 基础扫描

在终端中运行 SafeRunner，并根据提示输入需要检测的脚本绝对路径或相对路径：

```bash
./safe_runner.sh
# 提示输入: 请输入要检测的脚本路径: /path/to/your/script.sh
```

### 4.3 命令行直接传参 (推荐)

为了更方便地集成到自动化流程中，支持直接将目标路径作为参数传入：

```bash
./safe_runner.sh /path/to/your/script.sh
```

### 4.4 解读扫描报告

扫描完成后，SafeRunner 会输出结构化的安全报告：

- **无威胁**：若未发现风险，将输出 `>>> 扫描结论: 暂未发现明显威胁 <<<` 并以状态码 `0` 退出。
- **发现威胁**：若命中危险特征，将列出警报类型与代码证据，输出 `>>> 扫描结论: 极度危险 (千万别跑) <<<` 并以状态码 `1` 退出。

## 5. CI/CD 流水线集成

SafeRunner V18.1 极其适合嵌入到 GitLab CI、GitHub Actions 或 Jenkins 中作为准入卡点。以下是一个简单的 Shell 执行示例：

```bash
# 在流水线中执行扫描
./safe_runner.sh ./deploy.sh

# 检查退出状态码，若为 1 则中断流水线
if [ $? -ne 0 ]; then
    echo " 安全扫描未通过，请检查脚本中的高危操作！"
    exit 1
fi
echo " 安全扫描通过，继续部署流程..."
```
